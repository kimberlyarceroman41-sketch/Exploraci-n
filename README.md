# DATANEXUS - Guía Interactiva de Big Data

Este archivo ZIP contiene la aplicación web completa e interactiva **DATANEXUS**.

## Contenido del paquete:
- `index.html`: Código fuente completo de la aplicación (HTML5, Tailwind CSS, JavaScript y FontAwesome).
- `README.md`: Instrucciones y documentación del proyecto.

## Instrucciones de uso:
1. Extrae todos los archivos del archivo ZIP.
2. Haz doble clic en el archivo `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
3. No requiere instalación de servidor local ni dependencias adicionales (utiliza CDN para los estilos de Tailwind CSS e iconos).
